# Support

Questions about Experiment Ledger's scope, contribution process or commercial licensing can be sent to protoscience@anulum.li.

The repository foundation is under construction. No installed Ledger package, hosted service, service-level commitment or production support is available. Read [the current scope](README.md) and [architecture](ARCHITECTURE.md) before reporting missing runtime behaviour.

For a source issue, include the exact revision, environment and a minimal non-sensitive example. Security reports use the private route in [SECURITY.md](SECURITY.md).
