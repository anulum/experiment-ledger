# Governance

Miroslav Šotek, ANULUM, owns project direction, licensing and publication decisions. Changes are reviewed against the repository's architectural boundary, complete implementation contract and actual evidence.

The project is preparing a local repository foundation. There is no hosted service, public release or qualified runtime capability to govern as an existing product.

Maintainers retain original evidence and distinguish proposals, accepted source contracts, implemented behaviour and qualified results. An implementation or test result does not automatically authorise publication, release, deletion, service activation or a broader scientific claim.

Contributors propose changes with their relevant source, user-visible behaviour, validation and licence provenance. See [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md).
